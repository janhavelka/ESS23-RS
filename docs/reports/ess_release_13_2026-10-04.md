## Independent audit and corrections

Configuration-effects/source and limits/reference reviewers checked original
pages, current code and actual callers; a separate console reviewer checked
correlation, bounded output and host evidence. Root verified findings against
the integrated diff. Confirmed gaps fixed during integration:

- Early stationary-budget expiry is a valid deadline event even before the
  overall operation deadline; it cannot strand the context or replay a write.
- Enabling binds caller-qualified signed bounds to the exact retained raw
  pairs, same configuration reference and fresh homing-complete evidence, and
  rejects a released axis even if its old homing flag remains set.
- Accepted writes invalidate knowledge before ACK. External driver/config
  reads apply equivalent scale/polarity/reference effects; old state/config
  continuations cannot refresh a new interpretation.
- Direction uncertainty gates engineering move/velocity admission as well as
  host previews; declaring only a new scale cannot restore an old sign.
- Python rejects forged failure outcomes contradicting a complete successful
  sequence, and checks attempted-time and stationary-budget provenance.
- Configuration generations are distinct from transport bindings. Secondary
  address updates are explicitly unavailable in the single-axis example.

Final independent source/application re-review reports no remaining confirmed
software defect. No duplicated queue, scheduler, raw write bypass, buffer growth
or rollback machinery was added.
