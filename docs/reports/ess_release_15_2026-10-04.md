## Independent review and corrections

Assigned terminal/mask source and external-effect reviewers, with a separate
core author. Reviewers inspected the integrated source, callers and tests;
the lead checked findings against the actual diff and original pages. Relevant
FieldCore RS485 owner/backend paths were reinspected read-only: current
request-identical prefix stripping and immediate cancellation settlement are
not appropriate motor-result policies. Its sensor/measurement payload and
framework types remain outside this library. No FieldCore files changed.

The review corrected reserved-mask overwrites, narrowed custom actuation to
the documented terminal-bit/canonical subset, and required prior as well as
final no-function before the standalone qualifies an input-polarity change.
Its automatic input reassignment qualification now covers only transitions
between already known none/origin/limit assignments; an existing release/stop/
speed/JOG function requires independently established effects. All other typed
choices remain usable by direct callers with real supplied qualifications.
The reported write budget now includes the older I/O evidence cutoff, matching
the core deadline. Exact candidate field qualifications cannot cover omitted
combined changes. DRIVE cannot opt into the I/O-only echo/readback policy.

The first physical campaign failed before any settings write: the actual I/O
admission line reported `done` rather than `accepted`, because the shared
console acknowledgement classifier omitted `io`. The strict Python parser
rejected this framing contract and did not retry. The raw failed log is retained.
The classifier was corrected, a native actual console/application/owner path
and explicit accepted-line regression added, and the same initial scenario plus
the complete feature/regression campaign rerun on the corrected image.
No motor-write failure was hidden or replayed. A fake reference fixture was
also corrected to provide its required age/binding; old tests now reflect the
application's explicit UNCONNECTED wiring while retaining unknown input levels.
