## Review findings and corrections

Assigned diagram/prerequisite and state/reference reviewers, plus a separate
core author; independent reviewers audited the final code/callers/diff instead
of relying on predecessor reports. Lead verified findings against source and
registered reproductions. The integrated review corrected:

1. Generation exhaustion after accepted staging could permit continuation and
   republish native confidence under generation0. Continuation and publication
   now require a live generation; the accepted setup and uncertainty remain.
2. A boolean low-transition witness could outlive the frame proving it. The
   first post-trigger low frame and its conservative eligibility are retained.
3. Method35 has no search trajectory. Unexpected RUNNING now fails explicitly;
   a later homed/zero report cannot establish a reference from external motion.
4. Stored qualifications did not bind the selected method/native words, so a
   qualified snapshot could authorize different mechanics or parameters. Exact
   method/search/return/ramp witnesses now must match before staging; CLI intent
   cannot fill those witnesses. Direct, application and JSON forgeries regress it.
5. Python rejected valid late-ACK deadline failures, and accepted fabricated
   activity/low alarms or impossible stage/trigger/observation token ordering.
   Checked wire/source classification is separated from deadline failure;
   full retained causal evidence is validated, including stage-before-trigger.
6. An older cached RUNNING/RELEASED observation from the search could erase a
   newly completed reference. It is ignored only when its qualified upper bound
   strictly precedes the new reference lower bound. Overlapping/newer evidence
   still invalidates confidence; host origin changes still need fresh stationary
   cache evidence. Five actual-application regressions cover these boundaries.

C++11 test-lambda/default and chained-if compiler errors were corrected.
One simulated stop fixture omitted an explicit stop policy and correctly
rejected admission; the fixture now supplies configured deceleration.
Initial inventory assertions were updated for narrow implemented method/start
choices and zero-offset IN_PROGRESS, with a new regression denying auxiliary
setter/other-method credit. An installed-consumer check initially reused an
older CMake package cache; a separate clean consumer directory proves the new
installed headers/core. No stale executable was used as final evidence.
